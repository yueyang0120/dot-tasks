# DOT Tasks

**整理待办，分清轻重缓急，让你的 DOT 持续推进。**

把散在你和 DOT 对话里的真实待办整理到一个能查看、编辑的列表里：

- 识别事项、关联已有任务，结合要求、期限和影响判断 P0 / P1 / P2。
- 让已连接的 DOT 选择可以推进的事项，查资料、备稿、跟进，再写回具体进展。
- 需要你决定、补资料或登录时，交回具体下一步；你可以暂停、改优先级或提改稿意见。

自主执行由你的 DOT 提供。这个 repo 提供任务数据、接口、界面和协作规则。只启动网页不会自动启动 DOT；后台推进需要真实连接和云端定时任务。

## 把链接发给 Dot，让它帮你装

在有 Sites 的 Dot、Codex 或 ChatGPT Work 对话里，复制这段：

```text
帮我安装这个工作台：https://github.com/yueyang0120/dot-tasks。按 README 完成安装，需要我操作时再叫我。
```

具体步骤在 [安装说明](SETUP.md)。每个人安装自己的一份私密实例；你的账号需要能使用 Sites 和 DOT，安装时会检查连接与后台任务。

## 一条命令看演示

Mac / Linux 装好 **Git 和 Node.js 22.13+** 后，在终端运行：

```sh
curl -fsSL https://raw.githubusercontent.com/yueyang0120/dot-tasks/main/install.sh | bash
```

脚本会下载到 `~/dot-tasks`，安装依赖、构建、初始化本地数据库，再启动演示。打开 `http://localhost:5173/?demo=1`，按 Ctrl+C 停止。也可以先看[脚本内容](install.sh)。

演示用虚构数据，不会连接你的 DOT。要装自己的实例，把上面的安装指令发给 Dot。重复运行会复用同一个 repo，保留数据，不拉取或覆盖源码。想换目录或端口：

```sh
curl -fsSL https://raw.githubusercontent.com/yueyang0120/dot-tasks/main/install.sh | bash -s -- --dir "$HOME/dot-tasks-demo" --port 5174
```

### 下载 ZIP 或使用 Windows

装好 Node.js 22.13 或更新版本，下载源码 ZIP，在解压目录打开终端：

```sh
npm run setup
npm run dev
```

打开打印的 `http://localhost:5173/?demo=1`。演示使用虚构数据，刷新恢复初始样例，不保存、不发送，也没有连接 DOT。

安装脚本安装锁定依赖、构建程序、初始化本地数据库。重复运行保留已有数据，不注册站点、不连接外部账号、不创建定时任务。

Bash 安装脚本还支持 `--no-start`（只安装）和 `--empty`（使用空白持久数据）。

要用空白的本地持久数据：

```sh
npm run setup -- --empty
npm run dev
```

打开打印的本地登录链接。这里是开发用模拟身份，不能证明真实 ChatGPT 登录或 DOT 接入成功。

## 让自己的 DOT 用起来

第一版采用**每人独立部署一份私密实例**：

1. 在能用 Sites 的 Codex / ChatGPT Work 中打开或提供这个 repo。
2. 复制 [SETUP.md](SETUP.md) 的提示词，在自己的账号下创建私密站点、独立数据库和站点插件。
3. 完成账号连接，用虚构任务验收整理待办、返回草稿和改稿交回。
4. 需要后台运行时，选择频率并启用云任务；核对一次真正的定时运行。

完整步骤见 [连接说明](docs/CONNECT-DOT.md)。安装提示词是接入引导，尚未在第二个账号完成端到端验收；账号的 Sites、插件和 DOT 权限仍是前提。

## 优先级与自主推进

P0 是有依据、需要优先处理的紧急或高影响事项；P1 是重要且可以正常推进的事项；P2 是能延后的事项。依据不足就保留待识别，不补虚构日期。你的手动修改要保留。

DOT 理解来源后判断优先级；服务端综合优先级、新交接、期限和上次检查时间选择就绪事项。暂停、完成、等待依赖或已被另一轮领取的事项不会重复推进。

## 当前边界

- 演示、本地持久数据和真实 DOT 接入是不同状态。
- 网页刷新只读取状态，不会唤醒 DOT。
- 一个实例只有一个私人工作区，不能开放给多人当成各自独立账号。
- 当前生产路径是 ChatGPT Sites；其他托管需要适配登录、数据库和 DOT 连接。
- 发送、提交等动作仍需准确授权，审核按钮本身不代表已经发送。

构建、测试和结构见 [English README](README.md)。独立项目，非 OpenAI 官方产品。
